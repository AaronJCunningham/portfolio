# Add an occult resource

1. Open a **Project** in Sanity.
2. Select **occult** under **Tags**, then publish.
3. It appears in `/community/resources` and opens at `/community/resources/your-slug`.

Leave Tags empty to keep an entry in the portfolio. Remove occult and publish to move it back. Hidden or unpublished entries are not listed. Cached pages refresh on a subsequent visit after up to one hour.

Deploy the updated Studio and website before using this on the live site. No existing articles have been tagged.
